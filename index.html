About Ali Coin

Ali Coin (ALIC) is a tribute cryptocurrency built in 2026 — a tribute to Ali, one of the most respected names in the Muslim world, and to everyone who has ever felt caught between the culture they were raised in and the world they now live in.

The project was created by a single developer working alongside artificial intelligence. Together, they forked Bitcoin Core, deployed a real blockchain to the cloud, and launched a live cryptocurrency — without funding, without a team, and without permission.

Ali Coin is built on the same foundations as Bitcoin:

  • 21 million supply cap
  • 50 ALIC block reward, halving every 210,000 blocks
  • 10-minute block times
  • Proof-of-Work mining

But Ali Coin is not just a fork. It's a tribute and a meeting place:

  • For those who carry the name Ali with pride
  • For those who grew up between two cultures
  • For those who want to reconnect with where they came from
  • For anyone who believes a small project, built with care, can grow into something meaningful

Ali Coin doesn't compete with Bitcoin.
It honors a name. It builds a bridge. It starts a community.

Founder Allocation

100,000 ALIC is allocated to the founder and reserved for community projects that honor the name Ali — starting with initiatives that support young people navigating life between cultures.

All allocations are visible and verifiable on-chain. The source code is open on GitHub.

This project has not been audited. Use at your own risk.

Build from Source

git clone https://github.com/bitcoin/bitcoin.git ali-coin
cd ali-coin
git checkout d25470d992b7

cp feerate.h src/policy/feerate.h
cp chainparams.cpp src/kernel/chainparams.cpp
cp chainparamsbase.cpp src/chainparamsbase.cpp
cp validation.cpp src/validation.cpp

cmake -B build -DBUILD_GUI=OFF -DBUILD_TESTS=OFF -DENABLE_IPC=OFF
cmake --build build -j4
